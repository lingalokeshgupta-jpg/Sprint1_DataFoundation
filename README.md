# Sprint 1 – Data Foundation

## Objective
Build a fully validated SQLite database (nifty100.db)
from 12 source Excel files.

## Technologies
- Python
- Pandas
- SQLite
- SQLAlchemy
- Pytest

## Dashboard Screens

### 1. Home
Displays KPI cards, sector breakdown, and top-performing companies.

### 2. Company Profile
Shows detailed financial metrics, revenue trends, profit trends, and company information.

### 3. Screener
Filters companies using financial metrics and allows CSV export.

### 4. Peer Comparison
Compares companies within the same peer group using radar charts and KPI tables.

### 5. Trend Analysis
Visualizes financial metrics across multiple years.

### 6. Sector Analysis
Displays sector-wise bubble charts and median KPI comparisons.

### 7. Capital Allocation
Shows capital allocation patterns using a treemap.

### 8. Annual Reports
Lists available annual report links for companies.
